Прогони гейт, который должен быть чистым перед любым коммитом, и почини всё, что упало.

```bash
uv run ruff format src tests
uv run ruff check src tests
uv run mypy
uv run pytest -q
```

Аргументы: $ARGUMENTS

## Правила починки

- Чини причину, а не симптом. `type: ignore`, локальные импорты внутри функций, ослабление
  настроек mypy/ruff и `# noqa` — не решения; mypy строгий над `src` и `tests`, тесты
  типизированы полностью.
- Упавший тест — сначала пойми, кто прав: тест или код. Если изменилось поведение осознанно,
  правится тест и объясняется почему; если нет — правится код. Не подгоняй ожидания под
  текущий вывод, не разобравшись.
- Тесты работают через фейки из `tests/fakes.py` и `World` из `tests/harness.py`; новый тест
  не лезет в приватные атрибуты и следует arrange-act-assert.
- Прогоняй гейт заново после каждой правки, пока все четыре шага не пройдут.
- Интеграционные тесты (`uv run pytest -m integration`, живой Sejm API) в гейт не входят —
  запускай их только если правка трогает адаптеры и сеть доступна.

## Отчёт

Коротко: что упало, что починил и почему именно так, что осталось (если что-то осталось —
скажи явно, не выдавай частичный результат за зелёный гейт).

Если в аргументах есть `--commit`, после зелёного гейта закоммить изменения с этим сообщением
(без `Co-Authored-By`, без пуша — пуш только если попросят отдельно).
