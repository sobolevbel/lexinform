# Corrections from the original amendment question

An eligible single-message correction uses the original publication's retained text question
when available. The complete original context supplies text, comparison, proposal and
recommendation. Existing delivery and pending-work guards apply before selecting the source.
The per-document cost check and run budget still apply. Existing legacy messages without the
question use the original refetch path.

A byte-identical prepared question retains an existing source receipt as lineage through the
original computation ID. It creates no fresh read observation or prepared receipt. If provider
fitting changes the question, the new snapshot records the actual returned question without
the old source map. A corrupt known reference fails the correction before refetch.
