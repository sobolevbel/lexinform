# Show retained original-card lineage on the operator history page

The explicit delivery history page adds one status line when the validated original
card has retained primary lineage and a recorded sent message. The line exposes no
document, result, source URL or internal identifier. Other publication history,
unconfirmed sends, legacy rows and the regular delivery lookup keep their prior
outputs.

The native writer test checks omission before send, omission when a parent is missing
and the positive page after standard expiry and restore. A separate before/after
replay retained exact legacy JSON and rendered Russian and English operator output.
