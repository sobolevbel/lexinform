# Prepared input coverage for loose RCL annexes

The loader already inserts normative annexes before the main document's explanatory tail.
The prepared-input map now composes that exact splice with trimming and budget fitting for
a loose RCL bill and its selected annexes. Each copied interval points to its own selected
part. Inserted page separators are generated intervals. The map requires matching selected
URLs and order, and exact equality with the assembled text.

The slice covers one main file, identified loose normative annexes and any admitted loose
supporting files in order. Other assemblies keep the existing behavior. The omission test
and selection policy are unchanged.

The frozen offline run compared independent cached and raw readers on 15 RCL stages.
Nine stages in each mode produced native requests. There were 36 prepared requests across
normal and tight cost profiles, with actual token recounts in 16 profiles. Twelve profiles
prepared no request. Request content and payload, selection and extracted text, ordered
reads, cost and reservation matched the baseline. Thirty stored prepared selections changed
only in analysis coverage. Selection state and normative-omission flags stayed unchanged.

Two baseline and two candidate runs reproduced their respective reports byte for byte.
The local replay uses pinned corpus files, the cached tokenizer and a refusing submission
seam. Raw and cached populations have separately recorded missing inputs. The cohort
measures stage rows and includes repeated document bodies.
