# Prospective amendment input receipt writer

Fresh ordinary amendment preparation retains the actual loaded source until its single provider
request preparation. Correction preparation enriches the intent inside its existing snapshot and
target transaction. A shared finite secondary capture hook serves supplements and amendments;
existing supplement helper interfaces and primary receipt behavior remain compatible.

The complete amendment context is hashed, while source ranges describe only normative text.
A later recommendation read cannot replace the normative parent. Resumed contexts without an
original capture, scans, packages, multipart inputs and unsupported Senate paths remain unstamped.
Optional metadata errors preserve preparation; cancellation still propagates. There is no new
provider call, schema, source body storage or reconstruction of legacy paid inputs.

Reader A was independently deployed and verified before writer publication. The byte-frozen
public preparation driver ran before runtime changes and after integration against eleven newly
acquired originals: twenty-two ordinary/correction paths preserve source, context, request,
preparation count, cost and status decisions. Fourteen text paths gain corroborated receipts;
eight scan paths remain unmapped, and the planned collection failure remains excluded. Prior
context and correction targets are controlled fixtures, not legal gold or historical paid evidence.

The metadata-only comparison uses actual prepared fixture states. Each text receipt adds 1,248
SQL bytes and 1,222 receipt JSON bytes; gzip grows 417 bytes for ordinary preparation and 402 for
correction. Scans add zero. Repeated saves preserve the entire dump; candidate and stripped copies
both restore idempotently. These measurements are not a production growth forecast.

Nine new unit cases and no new scenarios accompany 65 focused root tests. The full gate passes
8,343 tests, strict mypy over 729 files, Ruff and formatting; coverage is 92%. All 798 source/config
pins remain exact. On the pinned state copy, all 508 public bills and 201 changes, the entire
default doctor report, double restore and source database hash remain unchanged. Its zero queued
and submitting intents do not establish natural modern amendment coverage. DA5 remains partial.
