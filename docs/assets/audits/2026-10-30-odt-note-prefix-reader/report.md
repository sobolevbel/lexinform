DA3.3 остаётся частичным. DOC уже читает основной текст, footnotes и endnotes: `_spans` включает все три истории, `_read_pieces` читает их CP-диапазоны; это подтверждает `test_the_document_its_footnotes_and_its_endnotes_are_read_and_nothing_else`. Поэтому утверждение «читается только ccpText» неверно.

Однако связи вызов→сноска отсутствуют: `\x02` удаляется, таблицы ссылок не разбираются. Переназначение сноски при неизменных текстах может не изменить даже исходную извлечённую строку, следовательно, её нормализацию. Это вывод из кода, не результат нового corpus replay. Строки/ячейки частично восстанавливаются PAPX; при недоступных свойствах остаются табуляции. Field results сохраняются, коды отбрасываются; координаты, tracked changes и неподдержанные объекты не описаны структурно.

ODT имеет transient paths/spans/ассоциации, но J196 сохраняет только status/counts/hash с `contents=not_retained`. По хешу историю связей восстановить нельзя. Natural replay подтверждает четыре физические сноски, но они не выбраны default selection.
