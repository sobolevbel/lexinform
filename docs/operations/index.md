Статус: актуальная инструкция. Навигация проверена 24 сентября 2026.

| Задача | Инструкция |
| --- | --- |
| Проверить очередь, стоимость, выполнить команду | [Команды оператора](../operator-commands.md) |

Production state хранится SQL-дампом в ветке `state`. Проверки на реальных данных проводят
на копии с `lexinform run --dry-run`; такой запуск всё равно делает платные LLM-вызовы.
Рецепт подготовки копии — в
[CONTRIBUTING.md](https://github.com/sobolevbel/lexinform/blob/main/CONTRIBUTING.md#against-production-data).
