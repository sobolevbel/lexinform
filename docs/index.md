# Документация lexinform

lexinform находит польские законодательные инициативы, важные иностранцам, и сообщает
читателю, что изменилось, что будет дальше и когда ещё можно повлиять на решение.

## Как читать

Инструкции описывают рабочие правила; планы — желаемый результат. Датированные аудиты
сохраняют проверенный тогда снимок, а статус дефектов ведётся отдельно в реестре.
Закрытые расследования доступны в [архиве](archive/bugs.md).

[Гайды читателям](guides/README.md) доступны здесь для редакторской работы.
Этот локальный портал не публикует их на lexinform.pl.

Обзор продукта находится в корневом
[README.md на GitHub](https://github.com/sobolevbel/lexinform/blob/main/README.md).
Корневые README, CONTRIBUTING и `web/README.md` пока не входят в локальный поиск;
весь корпус `docs/` доступен через портал. Ссылки на GitHub требуют интернета.
