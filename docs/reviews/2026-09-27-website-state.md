## Воспроизведение

Команды выполняются из корня репозитория. Скрипт предназначен только для доверенного
dump из закреплённого state; безопасный импорт произвольного SQL — отдельный WEB-06.1.

```bash
git show beea36293a76c72d4fdaea544b3b0cdd2eb05c8b:lexinform.sql > /tmp/website-state.sql
uv run python tools/audit_website_state.py /tmp/website-state.sql \
  --commit beea36293a76c72d4fdaea544b3b0cdd2eb05c8b \
  --committed-at 2026-09-26T14:34:56Z --output /tmp/website-state-audit.json
```

Скрипт восстанавливает только свою временную БД, не читает `.env` и не подключается
к источникам. SHA/hash позволяют сравнить результат с сохранённой fixture.
